Proyecto destacado

Sistema de inventario para tienda

API REST para administrar los productos de una tienda y registrar sus entradas y salidas. Cada movimiento actualiza el stock automáticamente y el sistema impide vender más de lo que hay.

  • CRUD completo de productos y movimientos (10 endpoints)
  • Stock actualizado en transacciones, que se revierte al editar o eliminar un movimiento
  • Validaciones: nombres únicos, precios y stock no negativos, stock suficiente
  • Errores claros con su código HTTP (400, 404, 409) desde un manejador global
  • Arquitectura por capas y documentación interactiva con Swagger
